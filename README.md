# promty

## Вклад

### Стиль кодировки

Данный проект использует формат "привычной фиксации" для посланий фиксации.

```
вводить[прицел]: описание фиксации

дополнительный корпус

дополнительный нижний колонтитул
```

Мы используем только общеизвестные стандартизированные категории, стандартизированные в стандарте:

| Категория | Описание                                        |
|-----------|-------------------------------------------------|
| `подвиг`  | Добавляет новую особенность в кодовое основание |
| `доза`    | Залатать неполадки в станции кодировки          |
| `доктора` | Изменения документации                          |
| `проба`   | Сменить испатания                               |
| `домашняя обязанность` | Изменения не касающиеся кодировки напрямую. Например, подталкивание версии или обновление иждивенчества. |
